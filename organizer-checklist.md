# Secret Santa organizer checklist

## Before inviting anyone

- Name one organizer who can see the private participant list.
- Pick a firm join deadline and a separate gift deadline.
- Set a budget range, not just a maximum.
- Decide whether digital gifts, handmade gifts, or gift cards are allowed.
- Collect only the information actually needed: display name, delivery method, and optional wish list.

## Model exclusions explicitly

Write each forbidden giver-to-recipient pair down. Common examples:

- partners or members of the same household;
- last year's pairing;
- a manager and direct report;
- a participant who already knows another person's assignment;
- shipping restrictions between countries.

If a rule should work both ways, enter both directions. Run a feasibility check before sending assignments.

## Remote-team details

- Put time zones beside the reveal time.
- Choose a delivery method that works for every country represented.
- Give participants a private way to report a shipping or accessibility problem.
- Plan one fallback gift for a late delivery.

## After the draw

- Send each assignment privately.
- Do not publish the participant list or exclusion rules.
- Keep a re-draw plan for one withdrawal; avoid re-drawing everyone by default.
- Delete addresses and other delivery details when the exchange ends.
